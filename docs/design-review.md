# 공개 홈페이지 검수

## 2026-09-07 대시보드·서체·브랜드 정비

공개 페이지를 Wanted Sans로 통일하고, 제목의 굵기와 자간을 낮췄습니다. 차콜·웜그레이·세이지 계열로 대비를 조정했습니다. 세 면으로 구성된 T 심볼을 헤더·푸터·파비콘·공유 이미지에 사용합니다.

대표 대시보드 5종, 추가 화면 15종, 서비스 미리보기 3종을 공통 화면 시스템으로 다시 구성했습니다. 차트에는 축·단위·범례를 표시하며 지표와 상세 표가 같은 가상 데이터를 사용합니다. 문서 AI는 질문을 선택하면 사전 작성된 답변과 출처가 바뀝니다.

## 주요 검수 항목

- 운영 대시보드: 권역·기간 변경 시 지표·추이·표 갱신
- 모델 검증: 모델·임계값 변경 시 정밀도·재현율·F1·혼동 행렬 갱신
- 정책효과: 집단별 시행 전후 평균과 변화 차이의 일치
- 문서 AI: 선택 질문, 답변, 근거 문서의 일치
- 모니터링: 조회 구간의 요청 수·토큰 합계, 오류 필터
- 탭의 방향키 탐색, 추가 화면 펼치기, 키보드로 읽는 차트 값
- 좁은 화면에서 지표 2열, 차트 1열, 상세 표 내부 가로 스크롤
- 공개 페이지의 연락처·관리자 편집 키·내부 링크 유지

## 수정 위치

- 화면·데이터: `assets/js/analytics-view.mjs`
- 인터랙션: `assets/js/dash.js`, `assets/js/demos.js`
- 공통 스타일: `assets/css/design.css`, `assets/css/analytics.css`
- 정적 데모 재생성: `node scripts/render-demos.mjs`
- 데이터 일치 검증: `node --test scripts/analytics.test.mjs`

## 범위

Worker 인증·저장 API, 관리자 UI, 문의 데이터, DNS·Access·배포 설정은 변경하지 않았습니다. 모든 화면은 예시 데이터이며 이전 소속의 사업명·기관명·실측 성과를 표시하지 않습니다. GitHub 커밋을 검토한 뒤 기존 수동 배포 절차로 반영합니다.

## 검증 결과

데스크톱 1280px, 모바일 375px에서 5개 탭과 추가 화면 15종, 필터·질문·임계값 조작을 확인했습니다. 320px에서는 모든 공개 페이지의 가로 넘침과 차트 전용 축 배치를 확인했습니다. 데이터 일치 테스트 5개와 JavaScript 구문·HTML 링크·중복 ID·편집 키 검사를 통과했습니다.
