# 공개 홈페이지 검수

## 2026-09-07 분석 화면·브랜드 개편

대표 대시보드 5종, 펼쳐지는 세부 분석 15종, 서비스 미리보기 3종을 같은 원자료·집계·차트로 구성했습니다. 카드의 장식과 여백을 줄이고 차트, 분석 조건, 상세 표가 화면의 중심이 되도록 배치했습니다. 차트는 중간 폭의 패널에서도 읽을 수 있도록 패널 너비에 따라 축 배치를 전환합니다.

로고는 직접 그린 소문자 워드마크와 td 모노그램으로 통일했습니다. 공용 헤더·푸터·파비콘·대시보드·공유 이미지에 반영했습니다. Wanted Sans를 유지하며 차트는 청회색과 구리색을 중심으로 정리했습니다. 문의 문구는 분석 목적·보유 데이터·일정·산출물을 요청하는 직접적인 문장으로 수정했습니다.

## 분석 화면

- 데이터 탐색: 월별 중앙값과 IQR, 동일 폭 구간의 히스토그램, 권역별 결측과 중복 점검
- 모델 검증: 세 모델의 실제 합성 데이터 검증 점수, PR·AP·임계값별 오탐과 누락, 확률 보정과 변수 기여도
- 정책효과: 개체 단위 전후 변화 비교, bootstrap 구간, 기준 월 대비 시점별 변화, 하위 집단 추정
- 문서 AI: 사전 작성한 답변과 예시 원문, 구조화 필드, 인용 구간 연결
- 운영 분석: 같은 요청 로그에서 구한 지연 분위수·오류율·토큰 집계와 정상 요청의 단계별 시간

상세 화면은 현재 선택한 분석 조건을 전달받아 대화상자에서 열립니다. SAMPLE과 합성 데이터 안내를 유지하고 세부 방법은 접을 수 있는 분석 조건에 담았습니다.

## 수정 및 검증

원자료 생성·집계·차트·화면을 별도 모듈로 관리합니다. 자세한 편집 명령과 분석 방법은 README에 정리했습니다. 데이터 검증 테스트 6개는 원자료와 집계의 일치, AP 기준값, 혼동 행렬, bootstrap 기준 월, 요청 시간 합계, 전체 화면의 유효 수치를 확인합니다.

Worker 인증·저장 API, 관리자 화면과 문의 폼의 필드 계약은 유지합니다. 운영 반영은 GitHub 커밋 검토 후 기존 수동 배포 절차로 진행합니다.

## 확인 결과

1280px에서 대표 화면 5종과 상세 분석 15종의 전환, 권역·기간·모델·임계값·집단·구간 수준·문서 질문·요청 필터를 확인했습니다. 375px과 320px에서 전체 탭의 가로 넘침이 없으며, 상세 분석 대화상자의 차트 축과 닫기 동작을 확인했습니다. 서비스·수행 경험·회사소개·문의·개인정보 페이지도 320px에서 가로 넘침이 없습니다.

데이터 테스트 6개, JavaScript 14개와 Python 2개 파일의 구문 검사, 공개 HTML 8개의 파일 링크·중복 ID·관리자 편집 키 검사를 통과했습니다. 문의 폼의 기존 ID·6개 필드와 개인정보처리방침 본문이 유지되는 것을 비교했습니다.
