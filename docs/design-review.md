# 공개 홈페이지 검수

## 2026-09-07 디자인 개편

검은 첫 화면과 큰 한글 제목, 밝은 본문의 둥근 상단, 고정 목차와 번호 목록, 노란 문의 영역을 적용했습니다. 홈페이지·서비스·수행 경험·회사소개·문의·개인정보처리방침에 같은 디자인을 사용합니다.

## 확인할 동작

- 스크롤로 본문에 진입하면 헤더가 밝아지고 목차의 현재 위치가 바뀝니다.
- 목차를 클릭하면 해당 섹션으로 이동합니다. 모바일 목차는 헤더 아래에 표시됩니다.
- 모바일 메뉴를 열고 Escape, 메뉴 선택, 바깥 영역 클릭으로 닫을 수 있습니다.
- 데모 5개 탭을 클릭하거나 방향키/Home/End로 전환할 수 있습니다.
- 운영 대시보드의 지역/기간 필터가 KPI와 추이 차트를 갱신합니다.
- 각 데모 아래에서 추가 화면 3종을 펼치고 접을 수 있습니다.
- 서비스·수행 경험의 관련 화면 링크는 해당 데모를 선택합니다.
- 문의의 필수 항목과 개인정보 동의 검증, 제출 실패 시 입력 유지가 동작합니다.
- 관리자에서 편집하는 소개 문구, 문의 배너, 담당자·전화·이메일과 푸터 문구를 유지합니다.
- 애니메이션 감소 설정은 부드러운 스크롤, 등장 효과와 장식 애니메이션을 끕니다.

## 범위

Worker의 인증·저장 로직, 관리자 UI, DNS와 배포 설정은 변경하지 않았습니다. 운영 배포는 검수 후 기존 절차로 진행합니다.
