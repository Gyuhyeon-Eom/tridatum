# 공개 홈페이지 검수

## 2026-09-07 입체 모션과 업무 화면 개편

하나의 녹색 계열을 명도 단계로 나누어 페이지·내비게이션·로고·차트에 적용했습니다. 제목 최대 68px, 섹션 제목 최대 44px, 주요 본문 16–18px로 크기의 간격을 줄였습니다. 모션은 첫 화면의 입체 도형, 줄 단위 제목 등장, 짧은 페이지 전환, 스크롤에 따른 섹션 경계 변화로 구성했습니다.

입체 도형은 세 개의 둥근 프레임을 직접 모델링했습니다. 화면 내 버튼으로 층의 간격과 회전이 바뀌며 포인터·스크롤에도 반응합니다. three.js는 로컬 모듈로 제공하고 MIT 라이선스를 포함했습니다. WebGL 실패 시 CSS 도형을 표시하고, 모션 감소 설정과 비활성 탭에서는 반복 렌더링을 멈춥니다.

## 실제 업무를 기준으로 한 예시

확인 가능한 프로젝트 설명·분석 노트에서 기능 흐름을 추출하고, 사용자 요청에 있던 돌봄 분석 등을 합성 예시로 구성했습니다. 기존 기관명, 실제 건물·개인 위치, 수행 성과 수치를 전용하지 않았습니다. 지도는 가상 공간 배치이며, 예측·판단 화면은 실제 업무 시스템에 연결되지 않습니다.

서비스 페이지의 예시도 상권 매출·빈집 조사·문서 원문 대조로 변경했습니다. 공통 분석 모듈은 별도 파일로 보존하고, 공개 첫 화면은 가상 업무 기록을 직접 집계합니다. 현재 선택 조건의 CSV를 내보낼 수 있습니다.

## 검증 항목

- 12개 업무 화면의 전환과 모든 조건 값에 대한 유효 수치
- 지도·목록과 상세 레코드의 연결, 문서 원문 대조·확인 표시
- 교통 OD·유입·승차·하차 총계 일치
- 돌봄 수요 = 연계 + 미연계, 입력 레코드 = 적재 + 격리
- CSV 기록 수·이스케이프·조건 반영
- 공통 모델·패널·요청 데이터 테스트 유지
- 모바일 분야 선택·차트·목록 스크롤, 공개 페이지의 가로 넘침
- 공개 페이지 전환, 뒤로 가기, 메뉴와 문의 폼 계약 보존

운영 Worker·관리자 UI·DNS·Access 설정은 변경하지 않습니다. GitHub 커밋 검토 후 기존 수동 배포 절차로 반영합니다.

## 검수 결과

- 자동 테스트 11개 통과: 모든 조건의 수치, 레코드 연결, 집계 항등식, CSV 및 공통 분석 계산.
- 데스크톱에서 12개 분야 전환, 필터, 지도·목록 선택, 문서 확인 표시를 브라우저로 검수했습니다.
- 너비 375px와 320px의 독립 프레임에서 공개 페이지 6개와 업무 화면 12개의 가로 넘침이 없음을 확인했습니다. 모바일 제목·입체 도형·필터·문서 목록을 시각 검수했습니다.
- 문의 폼 ID·필드 6개, 개인정보처리방침 본문, 관리자 편집 키와 기본 문구를 비교했습니다. 실서버 문의 제출은 실행하지 않았습니다.
- 공개 페이지 이동 시 전환 레이어가 표시되고, 뒤로 가기 후 레이어 해제·입체 렌더링 복원을 확인했습니다. 최종 브라우저 오류 로그는 비어 있습니다.
