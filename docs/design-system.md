# 공개 홈페이지 디자인 규칙

사용자가 제공한 두 디자인 문서·미리보기·토큰 파일의 공통 규칙을 공개 사이트에 적용했습니다. 원본 구매 파일은 저장소에 복제하지 않았습니다.

## 기본값

| 항목                              | 적용값                                                   |
| --------------------------------- | -------------------------------------------------------- |
| 밝은 바탕 / 표면                  | #f3f3f3 / #ffffff                                        |
| 어두운 바탕 / 표면                | #050506 / #141416                                        |
| 주요 글자                         | 밝은 표면 #000000 / 어두운 표면 #ffffff                  |
| 보조 글자                         | 밝은 표면 #444444 / 어두운 표면 #b0b0b0                  |
| 강조                              | #fff100, 검은 글자와 조합                                |
| 경계선                            | 밝은 표면 #e5e7eb / 어두운 표면 #2a2a2c                  |
| 큰 섹션 / 카드 / 입력·버튼 모서리 | 28px / 16px / 8px                                  |
| 기본 간격                         | 5.3333, 10.6667, 16, 21.3333, 32, 53.3333, 62, 85.3333px |
| 한글 첫 제목 / 섹션 / 중간 제목   | 85 / 64 / 53px                                           |
| 리드 / 본문                       | 27 / 19px                                                |

가독성이 필요한 작은 글자는 원본의 faint 색상보다 진한 회색을 씁니다. 모바일은 제목과 패널 간격을 줄입니다. 업무 화면은 21px 제목, 22px 주요 수치, 11–13px 조작·표·패널 제목으로 밀도를 맞춥니다. 보조 축과 출처는 9–10px입니다.

## 서체

제공 파일에는 Suisse 서체가 없습니다. 문서의 대체 서체 제안에 따라 Archivo를 영문 디스플레이에 사용하며, 한글은 Wanted Sans로 구성했습니다. Archivo는 단순 가로 축소 없이 실제 폭 축 75%를 사용합니다. 영문 표제는 0.95 행간·700 굵기, 한글 제목은 1.1–1.13 행간·700 굵기입니다. 두 서체 모두 공식 배포와 OFL 라이선스를 포함하고 외부 폰트 요청 없이 제공합니다.

## 페이지 구성

- 메인: 회색 첫 화면, 흰 서비스 아코디언, 검은 업무 화면 섹션, 흰 작업 원칙, 검은 문의·푸터.
- 서비스·경험·소개: 어두운 첫 화면 이후 흰색·검은색 패널 교대.
- 문의: 어두운 첫 화면, 흰 본문과 회색 입력 카드.
- 상단 메뉴: 섹션의 밝기에 따라 로고·메뉴 색과 CTA의 검정/노랑을 전환.
- 기본 UI에는 그라데이션·광택·장식 그림자를 사용하지 않습니다. 입체 오브젝트의 조명·재질·그림자는 별도 시각 콘텐츠입니다.

## 상호작용

서비스 목록은 키보드로 조작할 수 있는 네이티브 details/summary입니다. 한 항목씩 펼치고 서비스 상세 링크로 이동합니다. 줄 단위 첫 제목 등장, 짧은 검은 전환 패널, 스크롤 리빌을 사용합니다. 모션 감소 설정에서는 이동 효과를 생략합니다.

입체 오브젝트는 직접 모델링한 세 개의 프레임이며 무채색 재질, DATA·MODEL·SYSTEM 표시, 작은 노란 중심부로 구성합니다. 버튼·포인터·스크롤에 반응하며 화면 밖과 숨은 탭에서 멈춥니다. 내부 페이지는 표제 중심으로 구성하여 WebGL 모듈을 로드하지 않습니다.

업무 화면은 왼쪽 분야 메뉴와 오른쪽 앱 셸로 구성합니다. 셸 모서리는 10px, 내부 패널은 6px입니다. 데스크톱은 뷰포트 높이에서 헤더와 유형 메뉴 높이를 뺀 공간에 맞춥니다. 주요 분석·원자료·지표 정의는 같은 자리를 전환하며, 긴 표와 검토 목록에는 내부 스크롤을 사용합니다. 빈집 순위에서 변수를 고르면 옆 차트가 바뀝니다. 1100px 이하에서는 분야 선택 상자로 전환합니다. 밝게/어둡게는 전체 문서를 재생성하지 않고 색상 토큰만 바꾸므로 현재 필터·선택·검토 표시가 유지됩니다. 노란색 외에 새로운 상태 색을 추가하지 않고 상태 이름과 도형으로 구분합니다.

기존 12개 합성 업무 데이터, 필터, 레코드 선택, CSV, 관리자 편집 키, 문의 API 계약을 유지합니다. 가격표·장바구니 등 구매 자료의 예시 화면은 회사의 서비스·문의 흐름에 맞는 컴포넌트 규칙으로 활용했습니다.

## 유형별 분석 화면

공개 메인 표제는 DATA INTO ACTION.입니다. 헤더에는 td 심볼을 노란색 바탕으로 표시하고 워드마크와 나란히 배치합니다.

대시보드는 4개 유형, 12개 분야, 36개 작업 화면으로 구성합니다. 상세 분석을 기본으로 열고 현황·검토함을 오갈 수 있습니다. 지역 군집·변수 순위·원자료 대조 등 분야별 내용은 `domain-workspaces.md`에 정리했습니다. 상세 화면은 공통 무채색을 유지하고 선택한 항목에만 강조색을 사용합니다.
