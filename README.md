# Tridatum 홈페이지

공공 데이터 분석 · AI 전문팀 Tridatum의 회사 홈페이지입니다.

## 구조

- `index.html` — 홈 (서비스 요약 · 핵심 실적 · CTA)
- `about.html` — 회사소개 (팀 · 일하는 방식 · 기술 스택)
- `work.html` — 수행 실적 (숫자 · 재발주 이력 · 프로젝트)
- `contact.html` — 문의 (연락처 · 진행 절차 · 계약 경로)
- `assets/style.css` — 공용 스타일
- `assets/fade.js` — 스크롤 페이드 (유일한 동작 효과)

## 로컬에서 보기

빌드 과정 없이 정적 HTML입니다. `index.html`을 브라우저로 열면 됩니다.

## 배포

GitHub Pages (Settings → Pages → Branch: `main`, root) 로 배포할 수 있습니다.
