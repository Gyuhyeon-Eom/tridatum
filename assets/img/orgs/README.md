# 기관 로고

이 폴더에 아래 파일명으로 공식 로고(가로형, 배경 투명 PNG 권장, 높이 60px 이상)를 넣으면
홈 화면 '함께한 기관' 스트립에 자동으로 표시됩니다. 파일이 없으면 기관명 텍스트로 표시됩니다.

|---|---|---|
| `mma.svg` | 병무청 | ✅ 적용 (위키미디어 공용) |
| `mpva.svg` | 국가보훈부 | ✅ 적용 (위키미디어 공용) |
| `reb.png` | 한국부동산원 | ✅ 적용 (공식 CI 배포 패키지) |
| `wdca.png` | 국립야생동물질병관리원 | ✅ 적용 (기관 홈페이지) |

| `sacheon.png` | 사천시 | ✅ 적용 (시 홈페이지) |
| `asan.png` | 아산시 | ✅ 적용 (시 홈페이지) |

공공기관 로고는 사용 규정이 있으므로 게시 전 확인을 권합니다.
