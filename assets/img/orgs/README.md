# 기관 로고

이 폴더에 아래 파일명으로 공식 로고(가로형, 배경 투명 PNG 권장, 높이 60px 이상)를 넣으면
홈 화면 '함께한 기관' 스트립에 자동으로 표시됩니다. 파일이 없으면 기관명 텍스트로 표시됩니다.

| 파일명 | 기관 |
|---|---|
| `mma.png` | 병무청 |
| `mpva.png` | 국가보훈부 |
| `reb.png` | 한국부동산원 |
| `wdca.png` | 국립야생동물질병관리원 |
| `keco.png` | 한국환경공단 |
| `sacheon.png` | 사천시 |
| `asan.png` | 아산시 |
| `kaia.png` | KAIA |

※ 각 기관 로고는 기관 홈페이지의 CI/상징 다운로드 페이지에서 받을 수 있습니다.
공공기관 로고는 사용 규정이 있으므로 게시 전 확인을 권합니다.
